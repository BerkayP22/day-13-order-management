# Sipariş yönetimi

**Gün 13 · C# günlük çalışma**

Ürün, müşteri, sipariş ve stok güncellemesini gösteren menülü C# konsol uygulaması.

## Çalıştırma

Visual Studio ile kökteki `.slnx` dosyasını açın veya `dotnet build` komutunu çalıştırın. Mevcut projeler .NET Framework 4.8 hedefler; Windows ve ilgili hedefleme paketi gerekir.

## İçerik

- `Program.cs`: konsol menüsü ve giriş akışı.
- `Product.cs`, `Customer.cs`, `Order.cs`: küçük model sınıfları.
- `.slnx` / `.csproj`: Visual Studio çözüm ve proje tanımları.

Bu repo, bir aylık öğrenme planının 13. günündeki küçük çalışma örneğidir.
